# CopyNinja

A featherweight **macOS clipboard manager** that lives quietly in the menu bar. Every text snippet and image you copy is captured, deduplicated, searchable, and one keystroke away — silently shuriken-style. 🥷

## Features

- **Menu Bar Popover** — a 360pt single-screen panel with Maccy-style two-line previews, `MM-dd HH:mm:ss` timestamps, and live search filtering. Transient popover: closes on Esc or outside click.
- **Keyboard First** — `↑↓` navigate, `Enter` copy, `Space` Quick Look preview, `Esc` close. The search field stays focused while arrows drive the list.
- **Quick Slots** — `⌘1`…`⌘9` and `⌘0` copy the top 10 items instantly; `⌘⇧1~0` extracts text via OCR instead (keys 3/4/5/6 are reserved by macOS screenshot shortcuts).
- **Image OCR** — Shift+click an image row (or hover it and press the `text.viewfinder` button) to extract its text on-device with Apple Vision (`VNRecognizeTextRequest`, ko-KR + en-US). Recognized text is registered as a brand-new top history entry.
- **Maccy-Style Watching** — background `NSPasteboard.changeCount` polling never blocks the UI. Sensitive data (`org.nspasteboard.ConcealedType`, `AutoGeneratedType`, `TransientType`) is never collected. Re-captured content is deduplicated: the existing entry is removed and pulled to the top.
- **Shuriken Icon** — the menu bar glyph is pure SwiftUI `Shape`/`Path` vector art (a four-bladed throwing star), rendered as a template image that follows the menu bar tint.
- **Persistence** — history (max 500 entries) is stored under `~/Library/Application Support/CopyNinja/`. Originals and thumbnails live as separate files so scrolling stays smooth (`NSCache` on top).
- **Clear All** — `⌘K` or `⌘⇧⌫` wipes in-memory history, on-disk storage, and the system clipboard in one stroke.
- **In-App Updates** — checks GitHub Releases once at launch (and on demand via the right-click menu or popover button). When a new version is found, a confirmation popup downloads and installs it — the app swaps itself and relaunches, no browser needed.
- **Launch at Login** — a toggle in the shuriken's right-click menu or the popover footer registers the app with Apple's modern `SMAppService`, so CopyNinja starts automatically after a reboot. No helper binaries, no launch daemons.
- **Tiny & Private** — a single self-contained binary. No third-party dependencies, no analytics, no tracking. Everything happens on your Mac.

## Requirements

- macOS 14 (Sonoma) or later
- Apple Silicon (arm64)
- Xcode Command Line Tools (for the Swift toolchain)

## Installation

Clone and build — no Xcode project required:

```bash
git clone https://github.com/dwyi84/CopyNinja.git
cd CopyNinja
./build.sh
```

`build.sh` compiles with Swift Package Manager, assembles `CopyNinja.app` (with an `LSUIElement` bundle so it lives quietly in the menu bar), signs it ad-hoc, and launches it.

Or grab the latest `CopyNinja-<version>.zip` from [Releases](https://github.com/dwyi84/CopyNinja/releases), unzip, and drag `CopyNinja.app` anywhere you like.

## Usage

| Action | Result |
| --- | --- |
| Click the shuriken in the menu bar | Open the clipboard history |
| `⌘⇧V` (anywhere) | Show / hide the popover |
| `↑↓` / `Enter` | Move selection / copy and close |
| `⌘1`…`⌘9`, `⌘0` | Copy the 1st–10th item instantly |
| `⇧Click` or hover → `text.viewfinder` | Copy OCR text of an image |
| `Space` | Quick Look preview of the selected item |
| Type in the search bar | Live filter the history |
| `⌘K` / `⌘⇧⌫` | Clear all (memory + disk + clipboard) |
| Right-click the shuriken | Quick menu: show / launch at login / check updates / clear / quit |

## Privacy

CopyNinja talks to two things only: your local pasteboard and the GitHub Releases API (only when you press "Check for Updates"). Clipboard content never leaves your Mac — OCR runs entirely on-device with Apple Vision.

## Development

Pure Swift Package Manager:

```bash
swift build -c release   # compile
./build.sh               # build, bundle, sign, launch
```

```
Sources/CopyNinja/
├── CopyNinjaApp.swift        # @main, status item, popover, keyboard monitor
├── ClipboardMonitor.swift    # background changeCount poller + sensitive-type filter
├── ClipboardStore.swift      # history, dedup, search, quick slots, OCR flows
├── ClipboardItem.swift       # entry model (text / image, OCR cache)
├── PersistenceManager.swift  # history.json + images/ under Application Support
├── ImageProcessing.swift     # PNG canonicalization + thumbnails (off-main)
├── ImageCache.swift          # NSCache for thumbnails and originals
├── OCRService.swift          # Vision text recognition (ko-KR + en-US)
├── HotKeyManager.swift       # Carbon RegisterEventHotKey (⌘⇧V)
├── UpdateChecker.swift       # GitHub Releases update check
├── LaunchAtLogin.swift       # SMAppService login-item toggle
├── NinjaIconView.swift       # vector shuriken + menu bar template image
└── Views/                    # popover, history rows, Quick Look overlay
```
